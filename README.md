# Understanding Evidence Synthesis

An open collection of reusable resources for teaching evidence synthesis across disciplines.

The project is built with [Quarto](https://quarto.org/) and is in an early stage of development. Its first module introduces effect sizes, precision and practical interpretation.

## Preview locally

Install Quarto and R, then run:

```bash
quarto preview
```

The current examples use base R and require the `knitr` package:

```r
install.packages("knitr")
```

## Structure

- `modules/` — self-contained teaching modules
- `slides/` — RevealJS presentations
- `exercises/` — student activities and facilitator materials
- `datasets/` — documented teaching datasets
- `templates/` — starting points for new contributions

See [CONTRIBUTING.md](CONTRIBUTING.md) before submitting material.
