# Contributing

Thank you for helping to improve the Understanding Evidence Synthesis Repository.

## Ways to contribute

- Report a methodological or technical error.
- Improve clarity, accessibility or documentation.
- Add an exercise, dataset, translation or worked example.
- Propose or submit a complete teaching module or slide deck.

For a substantial contribution, please open an issue before beginning so its scope and location can be agreed.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Start from a file in `templates/` where appropriate.
4. Render the project with `quarto render` and address errors.
5. Open a pull request describing the audience, learning outcomes, dependencies, testing and sources.

## Content expectations

Contributions should be methodologically defensible, clear about assumptions and uncertainty, and adaptable by other instructors. Examples should not imply that statistical computation can overcome weaknesses in study design.

Do not include copyrighted material without permission. Cite sources and identify adaptations. Do not contribute sensitive or personally identifying data.

By contributing, you agree that teaching content will be released under CC BY 4.0 and code under MIT, unless another compatible licence is clearly identified and agreed in advance.
